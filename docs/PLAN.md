# Состояние 0.9.0

Реализованы локальный CutAndFill, грубая проба Sharpening, упрощение с измеренным/строгим допуском, проверки кандидатов в памяти и единственный нормальный STL round-trip. Проверки каждой дыры ограничены пространственной областью изменённых граней. Отказ финального экспорта восстанавливает предыдущую стадию из RAM.

GUI работает с временными заданиями, имеет отдельное сохранение выбранных артефактов и защищает несохранённый результат при закрытии/смене исходника. CLI `--output` совместим. Время этапов, вычислительное устройство, причины отказов и положение мелких оболочек доступны в отчёте/журнале.

Реальный STL добавлен в обычный Git и регрессионные тесты (LFS отключён по согласованию с владельцем из-за квоты). На Linux, одном CPU, шаг 0,02 мм: 42 → 0 пересечений без вокселей, 36946 треугольников, 8,45 с; максимум исходник → результат 0,091008 мм. Полные замеры и команды воспроизведения — в README.

Следующие проверки на целевых системах:

1. Сборка Windows и исполнение новых тестов в существующей матрице CI.
2. RTX 3090: сравнить CPU/CUDA по stage_timings, voxel_passes и projection_backends; оценить RAM/VRAM.
3. Дополнительные реальные STL/OBJ, тонкие стенки, внутренние полости и 1–10 млн граней.
4. Работа OpenGL в Windows 10 и на разных драйверах; испытание больших сцен.

Общее отклонение ремонта от повреждённого исходника остаётся измерением по вершинам. Строгий допуск относится только к упрощению относительно исправленной поверхности. Измеренный/доказанный режимы явно различаются; качество вокселей скрыто не снижается.
