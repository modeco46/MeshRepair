# Состояние 0.4 и дальнейшая работа

## Реализовано

- Одна операция «Исправить», качество 0,001–0,5 мм.
- Необязательное схлопывание копланарных граней с углом 0–45° и адаптивное упрощение криволинейных участков.
- Проверка дополнительного отклонения упрощения по всей поверхности в обе стороны, относительно исправленной сетки; при неопределённости — откат упрощения без потери ремонта.
- Миллиметры всегда, автоматическое новое имя файла, ручная остановка без таймера.
- Прогресс по реальным этапам и callbacks, обработка в отдельном процессе.
- Автоматический выбор поверхностного ремонта/объединения или sparse OpenVDB winding reconstruction.
- Удалены отказы из-за 256 компонентов/100 млн ячеек.
- Проверяется сохранённый STL, включая численные дефекты после экспорта.
- Раздельные замкнутые оболочки сохраняются в одном файле с явным сообщением; мосты не выдумываются.
- Native CPU parallelism, опциональный CUDA winding и CPU fallback.

## Проверки

Тесты: диапазон качества и угла, сохранность исходника, автоматические уникальные имена, обратная ориентация, пересекающиеся/вложенные/раздельные тела, заполнение дыр, 1150 открытых компонентов с разреженным восстановлением, монотонный прогресс, CLI. Упрощение: плоские и кривые поверхности, сохранение углов, проверка внутренних областей треугольников и откат при неподтверждённом допуске. На Windows — реальная работа интерфейса, новых флажков и кнопки остановки. Собранный EXE проверяется отдельно, включая упрощение.

## Что ещё нужно

1. Реальные пользовательские STL/OBJ: снимки экрана не позволяют проверить восстановленную форму.
2. Профилирование на RTX 3090/64 ГБ и моделях 1–10 млн треугольников; время, peak RAM/VRAM.
3. Более надёжная интерпретация внутреннего объёма для хаотичных нормалей и крупных дыр.
4. Отдельная оценка новых заплаток, удалённых внутренних поверхностей, потери мелких элементов.
5. Контроль отклонения всего ремонта от исходника, отдельно от уже реализованной численной оценки дополнительного упрощения; ускорение проверки на крупных сетках.
6. Встроенный 3D-просмотр, проверка Windows 10, подпись и стабильные Releases.
