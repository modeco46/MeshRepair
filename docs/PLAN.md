# Состояние 0.3 и дальнейшая работа

## Реализовано

- Одна операция «Исправить», единственный параметр обработки — качество 0,001–0,5 мм.
- Миллиметры всегда, автоматическое новое имя файла, ручная остановка без таймера.
- Прогресс по реальным этапам и callbacks, обработка в отдельном процессе.
- Автоматический выбор поверхностного ремонта/объединения или sparse OpenVDB winding reconstruction.
- Удалены отказы из-за 256 компонентов/100 млн ячеек.
- Проверяется сохранённый STL, включая численные дефекты после экспорта.
- Раздельные замкнутые оболочки сохраняются в одном файле с явным сообщением; мосты не выдумываются.
- Native CPU parallelism, опциональный CUDA winding и CPU fallback.

## Проверки

Тесты: диапазон качества, сохранность исходника, автоматические уникальные имена, обратная ориентация, пересекающиеся/вложенные/раздельные тела, заполнение дыр, 1150 открытых компонентов с разреженным восстановлением, монотонный прогресс, CLI. На Windows — реальная работа интерфейса и кнопки остановки. Собранный EXE проверяется отдельно.

## Что ещё нужно

1. Реальные пользовательские STL/OBJ: снимки экрана не позволяют проверить восстановленную форму.
2. Профилирование на RTX 3090/64 ГБ и моделях 1–10 млн треугольников; время, peak RAM/VRAM.
3. Более надёжная интерпретация внутреннего объёма для хаотичных нормалей и крупных дыр.
4. Отдельная оценка новых заплаток, удалённых внутренних поверхностей, потери мелких элементов.
5. Строгая непрерывная проверка отклонения поверхности вместо отождествления шага с точностью.
6. Встроенный 3D-просмотр, проверка Windows 10, подпись и стабильные Releases.

Одна кнопка не отменяет неоднозначность повреждённой геометрии и ограничения ресурсов. Не выдавать ложный успех, не снижать качество скрыто, не обещать одну связную оболочку для физически раздельных деталей без добавления геометрии.
