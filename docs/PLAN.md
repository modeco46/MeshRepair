# Состояние 0.7 и дальнейшая работа

## Реализовано

- Одна операция «Исправить», качество 0,001–0,5 мм.
- Новый Qt-интерфейс, перетаскивание STL/OBJ/PLY, копирование/очистка логов, сохранение настроек.
- Отдельная проверка без ремонта: общая статистика, самопересечения, дыры и таблица замкнутости оболочек.
- VTK/OpenGL-предпросмотр всех треугольников: поверхность, рёбра, вращение, масштаб, исходник/результат.
- Необязательное схлопывание копланарных граней с углом 0–45° и адаптивное упрощение криволинейных участков.
- Проверка дополнительного отклонения упрощения по всей поверхности в обе стороны, относительно исправленной сетки; при неопределённости — откат упрощения без потери ремонта.
- Миллиметры всегда, автоматическое новое имя файла, ручная остановка без таймера.
- Прогресс по реальным этапам и callbacks, обработка в отдельном процессе.
- Автоматический выбор поверхностного ремонта/объединения или sparse OpenVDB winding reconstruction.
- Удалены отказы из-за 256 компонентов/100 млн ячеек.
- Проверяется сохранённый STL, включая численные дефекты после экспорта.
- Раздельные замкнутые оболочки сохраняются в одном файле с явным сообщением; мосты не выдумываются.
- Native CPU parallelism с числом частей по доступным CPU, опциональные CUDA winding и проекции, CPU fallback без изменения допуска.

## Проверки

Тесты: диапазон качества и угла, сохранность исходника, автоматические уникальные имена, обратная ориентация, пересекающиеся/вложенные/раздельные тела, заполнение дыр, 1150 открытых компонентов с разреженным восстановлением, монотонный прогресс, CLI. Упрощение: плоские и кривые поверхности, сохранение углов, проверка внутренних областей треугольников и откат при неподтверждённом допуске. На Windows — реальная работа интерфейса, новых флажков и кнопки остановки. Собранный EXE проверяется отдельно, включая упрощение.

## Что ещё нужно

1. Расширить набор реальных STL/OBJ: один предоставленный тест проверен, нужны другие сложные модели.
2. Профилирование на RTX 3090/64 ГБ и моделях 1–10 млн треугольников; время, peak RAM/VRAM.
3. Более надёжная интерпретация внутреннего объёма для хаотичных нормалей и крупных дыр.
4. Отдельная оценка новых заплаток, удалённых внутренних поверхностей, потери мелких элементов.
5. Контроль отклонения всего ремонта от исходника, отдельно от уже реализованной численной оценки дополнительного упрощения; ускорение проверки на крупных сетках.
6. Испытание встроенного 3D-просмотра на реальных 10-миллионных моделях и разных видеодрайверах; проверка Windows 10, подпись и стабильные Releases.

Дополнительно проверяются: Check без записи исходника, открытые/закрытые оболочки, полный перенос треугольников в VTK, перетаскивание, копирование выделения и всего журнала, очистка, CPU fallback при ошибке CUDA. OpenGL-отрисовка проверяется в Linux/EGL; CI Windows проверяет Qt, данные сцены и готовый EXE без наличия аппаратного GPU.

Одна кнопка не отменяет неоднозначность повреждённой геометрии и ограничения ресурсов. Не выдавать ложный успех, не снижать качество скрыто, не обещать одну связную оболочку для физически раздельных деталей без добавления геометрии.

## 0.6

Реализованы согласование ориентации до выбора алгоритма (SciPy native parity graph), три попытки упрощения, строгий и явно измеренный режимы допуска, защита мелких островов, векторная смежность и пакетный доступ к проекциям, русская панель отчёта, контроль исходник → результат, NaN/inf, отдельный файл результата worker и очистка временной папки задания. Проверки реальных пользовательских моделей и RTX 3090 остаются необходимы.

## 0.7

Упрощение воксельных стыков с угловым взвешиванием QEM, один общий проход вместо последовательных плоского/криволинейного, сохранение малых оболочек вне дециматора. Проверены предоставленный STL и численная граница отклонения от плотного ремеша. Контроль всего ремонта относительно повреждённого исходника остаётся отдельной задачей.
