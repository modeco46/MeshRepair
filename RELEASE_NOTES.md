# MeshRepair 0.8.0

Полный комплект приложения Windows x64. Распакуйте весь ZIP и запустите MeshRepair.exe; папка _internal должна оставаться рядом. Компиляция не нужна.

- Компактный однострочный header 46 px и двухколоночный интерфейс с увеличенным предпросмотром.
- Очистка вырожденных граней проверяется после записи STL и откатывается при дефектах.
- Простые дыры заполняются до вокселизации при любом их количестве, с проверкой и откатом каждой заплатки.
- Восстановление острых рёбер Sharpening включено по умолчанию; невалидный результат откатывается на обычный ремеш с тем же шагом.
- Неориентируемая часть больше не блокирует исправление нормалей остальных тел.
- Кнопка «Отклонения», карта расстояний всех исходных вершин, топ-10 координат в отчёте.
- Несовместимая раскладка проекций выдаёт явную ошибку вместо замедления.

Числа в README относятся к указанным контрольным моделям. На шуме и тонких стенках Sharpening может давать шипы. Карта односторонняя и не является доказательством точности всего ремонта. На реальном test.stl максимальное отклонение осталось около 0,107 мм при шаге 0,02 мм; приложение сообщает это предупреждением.

Архив EXE взят из успешной сборки точного коммита main. Полные исходники, включая тесты, доступны ниже как Source code (zip). Контрольная сумма ZIP — в SHA256SUMS.txt.
