# MeshRepair 0.9.1

- Невалидный полный Sharpening автоматически заменяется обычным offsetMesh при оценке повторного расчёта до 120 с. Для более дорогого расчёта есть кнопка «Повторить без Sharpening» с прежними настройками. Причина и время видны в отчёте. CutAndFill к полному Sharpening не применяется.
- Заплатки с самопересечениями принимаются условно и исправляются общим локальным CutAndFill в пределах порога. При неудаче они полностью откатываются, включая изменения старых вершин, и выполняется воксельный путь.
- На регрессионной сфере R=5, UV 200×200: 38 → 0 дыр, четыре заплатки исправлены, 23 → 0 пересечений, одна замкнутая оболочка, 76 904 треугольника, отклонение поверхности 0,03466 мм, 3,50 с на CPU. Воксели не потребовались.
- CUDA winding повторно используется между проходами; нативная многопоточность и проверки в памяти сохранены. Измерения CPU и проверки CUDA-интерфейса не заменяют измерения на физической GPU.
- Все PR, включая внутренние, запускают Linux/Windows тесты и сборку Windows EXE до merge. Автономный тест собранного приложения защищён от импортов исходного пакета. Публикация использует только проверенный коммит main.
- Добавлены сквозные регрессионные тесты engine.run и проверка кнопки повтора. Русский интерфейс сохранён.
