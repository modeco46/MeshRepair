# MeshRepair 0.9.0

- Малые дефекты исправляются локально CutAndFill до вокселизации. На предоставленном `test.stl`: 42 → 0 пересечений, 36946 итоговых треугольников, 8,45 с на одном CPU без CUDA вместо 269,6 с у 0.8.1. Максимальное отклонение исходника — 0,091008 мм; две замкнутые оболочки сохранены.
- Sharpening допускается после проверенной пробы с шагом ×4. Один полный воксельный расчёт; отдельной повторной проверки Sharpening нет. Если полный результат невалиден, он не публикуется; можно повторить с выключенным Sharpening.
- Упрощение начинается с error_scale=0,25, повторный масштаб учитывает измеренную ошибку. По умолчанию допуск измеряется в обе стороны по вершинам; доказательство всей поверхности выполняется только по галочке. Отказы и откаты видны в отчёте.
- Проверки заплаток учитывают только изменённые грани и их пространственных соседей. Кандидаты очистки/упрощения остаются в RAM. Итоговый STL записывается и перечитывается один раз; при дефекте экспорта предыдущая стадия восстанавливается из памяти.
- «Сохранить…» / Ctrl+S позволяет выбрать STL, JSON, карту отклонений и журнал. Автосохранение выключено по умолчанию. Есть подтверждение перезаписи, защита исходника, запись через `.part` и `os.replace`, вопрос о несохранённой геометрии.
- Все задания и предпросмотр — в системном temp или выбранной папке/RAM-диске; проверяется свободное место. Владельцы отмечены `owner.pid`, добавлены очистка при выходе/остановке/смене файла и уборка старых осиротевших заданий.
- Новые настройки: удаление оболочек <50 граней (выключено), «Без CUDA», папка временных файлов. Журнал содержит время этапов и compute_device; GUI сообщает ожидание каждые 5 с без прогресса.
- Добавлены реальный STL в обычном Git (по согласованию с владельцем, без зависимости от квоты LFS), регрессии CPU, хранения и Qt-сохранения, benchmark до/после. CLI с явным `--output` совместим. Правила push/PR сохранены; готовый Windows ZIP публикуется в Releases по проверенному тегу.

Подробные замеры и ограничения — в README. Windows и аппаратная CUDA требуют проверки на соответствующем оборудовании; измерение по вершинам не является доказательством отклонения всей поверхности или точности ремонта относительно исходника.
